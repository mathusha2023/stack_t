# САМЫЙ КРУТОЙ И БЕЗОПАСНЫЙ СТЭК НА ДИКОМ ЗАПАДЕ

> Реализация классической структуры данных - стэк - с максимальным упором на безопасность, 
если кто то сможет его сломать - получит от деда энергос

---

## Что реализовано?

* Сама структура данных - Stack - с набором функций для взаимодействий с ней
* API для взаимодействия со стэком: 
    - init_stack
    - push_stack
    - pop_stack
    - destroy_stack
    - is_stack_empty
    - is_stack_ok
* Защита стэка в виде огромного количества проверок от всех видов ошибок
* Канареечная защита стэка от нечаянных выходов за его границы или каких либо
попыток изменить его данные извне
* Хэширование структуры стэка для полной защиты всех полей: ни одно нелегальное изменение какого либо поля стэка не останется незамеченным
* "Мягкая" обработка ошибок: все функции взаимодействия со структурой возвращают StackError,
которую программа дальше должна обработать кастомным образом, что дает гибкость использования структуры
* Полное логирование всех действий, происходящих со стэком, и возникающих в нем ошибок
* Возможность включить / выключить debug-режим с помощью одного дефайна

## Запуск

Склонируйте репозиторий с проектом 

```
git clone https://github.com/mathusha2023/stack_t
```

Перейдите в папку с копией проекта

```
cd stack_t
```

Для компиляции введите 

``` 
chmod +x ./build.sh
./build.sh
```

Программа запускается командой

```
./stack
```
